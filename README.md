# Chaos Game Explorer

Roll a die, jump toward the corner it picks, leave a dot. Repeat a million times.

An interactive companion to the Cleo Cat video [The Chaos Game](https://youtu.be/3bIOdZJoVr0): every shape from the
video and more (the cube family, Menger sponge, Kepler's star, the fern), live in the browser with WebGL2.
One self-contained file: `index.html`.
